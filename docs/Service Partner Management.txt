Method
Endpoint
Description
GET
/api/admin/service-partners
Basic Details List for table view (supports search, filters, pagination)
GET
/api/admin/service-partners/:id
Complete Details when clicking "View Details" (profile, bank, timing slots, vehicle supports, order stats)
PUT
/api/admin/service-partners/:id
Edit service partner details (center name, address, contact, city, state, lat/long)
PATCH
/api/admin/service-partners/:id/toggle-status
Enable / Disable service partner (is_active toggle)
GET
/api/admin/service-partners/:id/orders
Orders List for Partner (supports tabs: all, upcoming, completed, cancelled)
GET
/api/admin/service-partners/:id/orders/:order_id
Complete Order Details for that partner's order


A. Service Partner List (Basic Details Only)
URL: GET /api/admin/service-partners?page=1&limit=10&is_active=true&search=Gurugram
Supported Query Filters:
search: Search by center name, owner name, mobile, city, pincode
is_active: true / false / all
city: Filter by city (e.g. Kosi Kalan, Gurugram)
pincode: Filter by pincode
onboarding_status: completed / pending
date_from / date_to: Registration date range
page, limit: Pagination controls

E. Service Partner Orders (With Tabs: upcoming, completed, all)
URL: GET /api/admin/service-partners/4/orders?tab=upcoming&page=1&limit=10
Supported Tabs:
tab=upcoming: Confirmed/Pending orders scheduled for today or future dates
tab=completed: Completed service orders
tab=cancelled: Cancelled service orders
tab=all: All orders for this partner
